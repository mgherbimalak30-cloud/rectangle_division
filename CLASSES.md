# Classes importantes

## MyApp
Classe principale de l'application.
Elle lance l'application avec `MaterialApp`.

## RectangleData
Classe qui représente un rectangle.
Elle contient :
- `Rect rectangle` : position et dimensions
- `Color color` : couleur

## HomePage
Classe qui représente la page principale.
C'est un `StatefulWidget` car son contenu change.

## _HomePageState
Classe qui gère l'état de `HomePage`.
Elle contient la logique :
- division des rectangles
- couleurs aléatoires
- choix de couleur
- dégradé
- bordures
- réinitialisation
